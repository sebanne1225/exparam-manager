ExParam Manager
BOOTH 配布パッケージ案内
version: 0.1.0

このツールは、VRChat アバターの Expression Parameters を可視化・逆引きし、削除・非同期化・bit 幅縮小を非破壊で行う NDMF ツールです。

主な方針:
- NDMF ビルド時のクローン上で処理されるため、元のアバターや元アセット（Expression Parameters / Menu / Animator）には直接変更を加えません
- コンポーネントを外すだけで元の状態に完全に戻せます
- Modular Avatar 未導入環境でもコンパイル・動作します

最初にやること:
1. GitHub repo の README を確認してください
2. まずは VCC / VPM で導入してください
3. アバターに ExParam Manager コンポーネントを追加し、「ExParam Manager ウィンドウを開く」から現在の bit 内訳と逆引き参照を確認してください

導入の基本:
- 主導線は VCC / VPM です
- Git URL 導入は補助扱いです
